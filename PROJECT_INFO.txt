===============================================================
  ULTIMATE PRO TRADING TERMINAL
===============================================================

Project Name : Ultimate Pro Trading Terminal
Version      : v4.1-terminal
Purpose      : Personal Trading Analytics / Education / Research

---------------------------------------------------------------
WHAT IT IS
---------------------------------------------------------------
A personal market analytics dashboard for Indian markets. It
pulls delayed price history from Yahoo Finance for Nifty 50,
Bank Nifty, Fin Nifty, MCX commodities and key indices, computes
a standard set of technical indicators, and presents them as one
consistent terminal-style view.

Symbols tracked : 68
                  - 50 Nifty 50 constituents
                  - 12 Bank Nifty
                  - 10 Fin Nifty
                  -  8 MCX commodities
                  -  3 index / currency instruments
                  (symbols shared between segments counted once)
Yahoo tickers   : 70 downloaded per refresh cycle
Refresh         : every 90 seconds (configurable)

---------------------------------------------------------------
PAGES (8)
---------------------------------------------------------------
  /                  Dashboard       Index cards, market pulse,
                                     top 5 bullish/bearish setups,
                                     watchlist, segment tables
  /screener          Screener        15 columns, bias filters,
                                     6 sort keys, search, CSV
  /heatmap           Heatmap         Coloured tiles by daily %,
                                     signal score or RSI
  /stock/<SYMBOL>    Stock Analysis  Indicator grid with per-cell
                                     timeframe, levels, summary
  /watchlist         Watchlist       Saved symbols with live price,
                                     score, trend and data age
  /markets           Markets         All segments plus currencies
  /options           Options Lab     Analytical strike ladder and
                                     validated P&L calculator
  /about             About           Indicator reference,
                                     architecture, security notes

---------------------------------------------------------------
FEATURES
---------------------------------------------------------------
  * 10 technical indicators per symbol:
    Big Candle (15M), MACD (1H), DOW Breakout (15M),
    EMA Crossover (5M), Bollinger Band (15M), RSI (15M),
    RSI Trend (15M), DMI (15M), ADX (15M), ADX Trend (15M)

  * Signal Score from -7 to +7, shown in five bands:
    STRONG BULLISH / BULLISH / NEUTRAL / BEARISH / STRONG BEARISH

  * Background batch data engine - four requests per refresh
    cycle for the whole universe, not one request per symbol

  * Snapshot cache - page requests never touch Yahoo Finance,
    so responses come back in roughly 10-20 ms

  * Stale-data recovery - a failed refresh keeps the last good
    snapshot and labels it, instead of blanking the dashboard

  * Timeframe transparency - when intraday data is unavailable
    the UI states "Requested: 15M / Using: Daily fallback"
    rather than mislabelling a daily value as intraday

  * NSE market session status: PRE / OPEN / POST / CLOSED

  * Global symbol search restricted to the known universe,
    with full keyboard navigation

  * CSV export per segment and from the screener

  * Dark and light themes, persisted per browser

  * Responsive down to 390px - wide tables become stacked cards

  * Optional Gemini assistant that receives the real current
    metrics for any symbol the user names

---------------------------------------------------------------
TECH STACK
---------------------------------------------------------------
Backend      : Python 3, Flask, Gunicorn
Market data  : yfinance (Yahoo Finance)
Computation  : Pandas, NumPy
Frontend     : Vanilla JavaScript, Bootstrap 5, custom CSS
AI assistant : Google Gemini (optional)
Deployment   : Docker (python:3.11-slim), Railway

No frontend build step. No chart library. No npm.

---------------------------------------------------------------
HOW TO RUN
---------------------------------------------------------------
Windows (easiest):
  1. Extract the ZIP
  2. Double-click START.bat
  3. Open http://localhost:5000

Manual (any OS):
  python -m venv venv
  venv\Scripts\activate        (Mac/Linux: source venv/bin/activate)
  pip install -r requirements.txt
  python trading_scanner.py

Docker:
  docker build -t ultimate-pro-trading-terminal .
  docker run -p 5000:5000 ultimate-pro-trading-terminal

Production:
  gunicorn --bind 0.0.0.0:$PORT --workers 1 --threads 8 \
           --timeout 120 trading_scanner:app

Use ONE worker. The cache and its refresh thread live in process
memory, so extra workers would each fetch their own copy.

The first load takes 10-15 seconds while the background worker
builds its first snapshot. See README.md for the full guide.

Requirements: Python 3.11 or newer recommended (verified on 3.11
via Docker and 3.13 locally). Internet connection required.

---------------------------------------------------------------
CONFIGURATION (all optional)
---------------------------------------------------------------
PORT             default 5000
REFRESH_SECONDS  default 90    (do not set below 60)
GEMINI_API_KEY   unset - assistant disabled, everything else works

Copy .env.example to .env for local configuration.
.env is gitignored and must never be committed or shared.

---------------------------------------------------------------
KNOWN LIMITATIONS
---------------------------------------------------------------
1. Prices are DELAYED Yahoo Finance data, not an exchange feed.
   The UI never claims "live" - it shows data age instead.

2. Timeframe fallback. When the provider does not return enough
   intraday bars, indicators are computed from daily bars. This
   is always labelled in the UI, never hidden.

3. Option premiums are ANALYTICAL ESTIMATES derived from spot
   price and strike distance. They are not exchange quotes, use
   no implied volatility or Greeks, and exclude all charges.

4. No market holiday calendar. Market status comes from the
   clock and weekday only, so an NSE holiday may still show as
   "Market Open".

5. Content-Security-Policy allows 'unsafe-inline' for scripts
   and styles because the markup uses inline event handlers.
   Every other CSP directive is strict.

6. Symbols outside the scanned universe are fetched on demand
   and cached for five minutes. The first such request takes a
   few seconds and is labelled "Off-universe symbol".

7. The watchlist lives in browser localStorage, so it does not
   sync across devices or browsers.

8. Commodity prices are approximate: Yahoo USD futures converted
   with the live USD/INR rate, not real MCX quotes.

9. No rate limiting. Fine for personal use; a public multi-user
   deployment would need it added.

10. No database. State is in memory, so a restart rebuilds the
    snapshot (10-15 seconds).

11. No historical charts in-app. TradingView and Groww links are
    provided instead.

---------------------------------------------------------------
SECURITY NOTE
---------------------------------------------------------------
No secrets are stored in this source tree. The Gemini key is read
only from the GEMINI_API_KEY environment variable - there is no
hardcoded fallback, and the value is never written to logs.

Every response carries Content-Security-Policy, X-Frame-Options,
X-Content-Type-Options, Referrer-Policy and Permissions-Policy.
Symbols are validated against a strict pattern before reaching
the data layer, all dynamic text is escaped before entering the
DOM, and errors never expose a stack trace to the visitor.

If you ever leak an API key, removing it from the file is not
enough - it remains in git history. Revoke it at the provider and
issue a new one.
