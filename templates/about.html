ABOUT THIS PROJECT

What it is, how it is built, and what the numbers actually mean.

About the project

Ultimate Pro Trading Terminal is a personal market analytics dashboard for Indian markets. It pulls delayed price history for Nifty 50, Bank Nifty, Fin Nifty, MCX commodities and key indices, computes a standard set of technical indicators, and presents them as one consistent view instead of ten separate chart tabs.

It is a learning and research project, not a trading system. Nothing here places orders, connects to a broker or promises an outcome.

What each indicator measures

Big Candle 15M Flags a bar whose high-to-low range is at least 1.5× the average of the last 10 bars. Bullish when it closed above its open.
MACD 1H Difference between the 12 and 26 period EMAs, compared with its own 9 period signal line. Bullish while MACD sits above the signal.
DOW Breakout 15M BUY when price clears the highest high of the previous six bars; SELL when it breaks the lowest low.
EMA Crossover 5M Golden while the 20 EMA is above the 50 EMA, Death when it is below.
Bollinger Band 15M Up when price reaches the upper band, being the 20 SMA plus two standard deviations.
RSI 15M 14 period Relative Strength Index. Below 30 is oversold, above 70 overbought. The trend column compares it with the previous bar.
DMI / ADX 15M 14 period directional movement. DMI is bullish while +DI leads −DI; ADX above 25 suggests the move has real strength behind it.
Signal Score Bullish signals minus bearish ones across seven indicators, so it runs from −7 to +7. It is a summary of the columns you can already see, not a separate strategy.
+4 and above · STRONG BULLISH +1 to +3 · BULLISH 0 · NEUTRAL −1 to −3 · BEARISH −4 and below · STRONG BEARISH

Architecture

The obvious approach — one API call per symbol per timeframe — is over 250 sequential network requests per page load. That times out on any cloud host and gets rate limited.

  1. A background thread wakes every {{ refresh_seconds }} seconds.
  2. It issues one batched download per timeframe (5M, 15M, 1H, 1D) covering all {{ universe }} symbols — four requests per cycle, not hundreds per visitor.
  3. Indicators are computed once and stored in an in-memory snapshot of plain values.
  4. Every page and API reads that snapshot, so requests answer in milliseconds and can never block on the data provider.

If a timeframe is throttled, indicators fall back to daily bars so cells degrade instead of going blank. If a whole refresh fails, the last good snapshot stays on screen and is clearly marked stale rather than being wiped.

Security

  • No secrets in the source — the Gemini key comes only from GEMINI_API_KEY.
  • Content-Security-Policy, X-Frame-Options, X-Content-Type-Options, Referrer-Policy and Permissions-Policy on every response.
  • Symbols are validated against a strict pattern before touching the data layer.
  • All dynamic text is escaped before it reaches the DOM.
  • Errors are logged server-side; visitors never see a stack trace.
